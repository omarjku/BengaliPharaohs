# Sample photos (demo + E2E tests)

Resized to 512 px (long side), JPEG q85. Each file's source name, true class and the model's prediction are in `manifest.json`. Several are deliberately wrong or unsure, to show the NOT SURE behaviour.

- `healthy-*`, `blast-*`, `brown_spot-*`, `blb-*`: from AgML_BD (Project-AgML, rice leaf disease classification, Bangladesh), licence CC BY 4.0. https://huggingface.co/datasets/Project-AgML/rice_leaf_disease_classification_bd
- `not_rice-*` (bean leaves): from iBean (AI-Lab-Makerere), licence MIT. https://github.com/AI-Lab-Makerere/ibean
